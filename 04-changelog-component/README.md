# Changelog Component

## About project

This is a simple Changelog component that tracks the progress of this challenge, created purely with HTML and CSS.

## How to run

Just download the folder and run the HTML pages, or load the folder inside VS Code and use the Live Server plugin to run it.

## Roadmap.sh

This project was completed as a learning challenge from Roadmap.sh. Project reference: https://roadmap.sh/projects/changelog-component
